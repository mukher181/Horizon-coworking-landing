# Horizon Coworking — Responsive Landing Page

A modern, mobile-first responsive web page designed for a professional coworking space, featuring an orchid-purple aesthetic.

## 📐 Page Sections
* **Header & Navigation:** Sticky header with a mobile hamburger toggle and desktop link menu.
* **Hero Section:** Value proposition, call-to-action buttons, and featured imagery.
* **Features Section:** Four-column flexible grid showcasing core workspace benefits.
* **Pricing Section:** Three-tier membership comparison grid with a highlighted popular plan.
* **Testimonials Section:** Customer reviews and member feedback cards.
* **Contact CTA:** Newsletter sign-up and inquiry form container.
* **Footer:** Multi-column link directory, address info, and copyright text.

## 📱 Responsive Breakpoints
* **Base (<600px):** Single-column stacked layout optimised for mobile touchscreens.
* **Tablet (>=600px):** Multi-column grids, horizontal action buttons, and side-by-side author cards.
* **Desktop (>=1024px):** Side-by-side hero split layout and full three-column pricing grid.
